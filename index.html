⚙️ 設定 ― Gemini APIキー

本番モードでは、アップロードした写真を Gemini API に送って日記を生成します。APIキーはこの端末のブラウザ内（localStorage）にだけ保存され、画面には表示されません。

キーが未設定のあいだはデモモードです。デモモードでは、内蔵題材のサンプル日記を表示します（写真アップロードの日記生成には本番モードが必要です）。
